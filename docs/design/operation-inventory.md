# Operation inventory

The current full-source inventory is in [the Araújo matrix](../coverage/araujo.md), with direct and transitive operators, methods, helpers and dependencies in [machine-readable coverage](../coverage/araujo.json). Its syntax, span, runtime and UI measures are separate. The table below records the original 0067-only baseline and is retained as implementation history; it is not the current capability list.

## Original baseline

This inventory describes Studio coverage, not everything Pydicate can express. Unknown source is retained for inspection and can receive independent reading/translation/note drafts. A syntax match alone does not grant full visual editing; detected contextual redefinitions of the slice's lexical names make it read-only.

| Operation or source construct | Studio coverage | Validation boundary |
|---|---|---|
| `nde * apiti * moro` | Typed subject/predicate/generic-object cards | Fixed lexical identities and left-associated argument structure; no arbitrary lexical replacement |
| Unary `+nde` | Subject visibility control | Expressed versus understood second-person subject |
| `.imp()` / default indicative | Mood selection | Only these two moods for this construction |
| Outer unary `-` | Whole-clause negation control | Exact outer scope over the selected mood; no arbitrary nested negation |
| Eight combinations above | Python-generated surface, annotations, morphemes; typed tree/code projections | Actual-engine snapshots and structural typed-model round trips |
| Diplomatic/normalized reading, translation, note | Independent editable drafts for every readable passage | Incomplete work can save; no reference or approval mutation |
| Source `l = [...]`, named source lists, and `+=` entries | Read-only AST discovery with original expression text | Current historic declarative list pattern; no corpus execution or source rewriting |
| Other `*` relations, `+`, `/`, `@`, `<<`, `>>`, `==` and other operator scopes | Inspectable source only | No claim of shared semantics or structural round-trip coverage |
| Constructors, lexical lookup, macros, aliases, variants, reference relations, derivations, subordinations | Inspectable source only | General visual adapters and authoring representation still required |
| Contextual `.definition` mutations and unfamiliar Python | Preserved source only | Not executed; not converted to new semantic claims |
| Saved references | Legacy comparison baseline | No automated acceptance, regeneration, or reference replacement |
| Contribution export | JSON draft/provenance artifact | No corpus write-back, publish action, or editorial approval |

The next representative additions from the brief are the Araújo 0074 relation/repair case and nested Bettendorff constructions. Each needs a source representation, explicit linguistic scope, and measured round-trip coverage before a visual editor can claim support. The [full design coverage matrix](pydicate-studio-design.md#coverage-of-the-actual-pydicate-language) remains a roadmap, not implemented capability.
