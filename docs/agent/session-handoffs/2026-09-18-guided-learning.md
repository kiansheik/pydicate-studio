## What worked

Each final lesson is the same AST as its approved source entry. Stage snapshots preserve actual annotations and partial failures. Concluding a lesson requires structure, annotation, surface and comprehension agreement. Progress and loose pieces use a separate validated storage namespace. Reference provides 24 Portuguese guides, 235 implementation/helper entries and all 129 source expressions at this snapshot, with source paths. Build uses local selected sibling repos without absolute home paths in the generated artifact. Desktop disables stale lessons rather than falling back to a misleading compiled success.

## What failed

An initial browser run reused another server on 5173 and saw blank pages, not this change. Dedicated test port 5197 avoids it. Test status selectors initially also matched canvas zoom; added accessible lesson status. The fixed-height practice wrapper initially clipped the editor's normal viewport; scoped flex sizing and compact tutorial-only controls corrected it. Two intermediate reflexive/variant forms do not independently realize; this is now explicit curriculum metadata, not hidden by a made-up surface. Vite's shared dependency cache initially hit sandbox EPERM; approved execution succeeded. Build retains the existing large-chunk warning.

## Remaining questions

- Ten minutes is a design estimate; a linguist/Tupi speaker should try the full sequence. No live AI inference was performed.
- The tutorial uses shared approved references, not any one person's private Concluídas list.
- The follow-up proposes choosing variants or nominalization until something renders. A clarification was offered between visible alternatives and automatic tree mutation. No engine change was made: `(mombeu * nhe).base_nominal()` and `.var(1).base_nominal()` both render, as `oîo mombe'u` and `nhemombe'u`. A valid output alone cannot choose the intended category/analysis.
- Routine question support uses the existing read-only explanation/history service, not the reconstruction queue. It cannot publish a proposed answer from the tutorial.
