1. Claude API generation is blocked by account credit; authenticated model discovery works. Recheck generation after billing is available. The critic's separate additional AI request with corpus context was denied by automatic approval review, and is not counted as executed.
2. Attach and assess the actual historical Araújo PDF. Native PDF geometry, persistence, rotation and original colors were verified with a vector fixture; unusual font/CMap/codec cases remain untested.
3. Package a contributor installer and tested Python environment. Current startup is reproducible with sibling clones at recorded revisions plus captured dirty patches; no bundled runtime is supplied.
4. Decide a portable contribution archive for managed PDFs, local draft history and AI provenance. Source comments retain stable evidence pointers; current Git export shares source/reference patches, not private local application data.
5. Unmarked identical insertion/reordering can be intrinsically ambiguous. Current code preserves stationary/unambiguous identities, uses explicit source IDs for durable edits, and keeps ambiguous orphan drafts for human reassociation. Avoid heuristic auto-migration of their PDF or AI evidence.
6. AI receives textual analysis/context and PDF identity/coordinates, not raster page pixels. Grammar repair responses remain separate proposals; an isolated engine-patch review workflow and automated remote PR publishing are future work.
7. Full Araújo coverage tests concrete syntax, selected visual interactions, selected-engine output and structural graphs. It does not prove every possible edit linguistically valid, or certify future engine constructs. Extend the explicit adapter/capability inventory for new operations.

Ordinary local implementation and disposable-copy tests are authorized. The task does not authorize silently applying experimental edits to the historical corpus, publishing credentials, or granting editorial approval from matching generated output.

8. If a real translation stalls again, inspect its persisted phase/request ID and local usage report. The repair made no new live generation requests by user instruction. Logs start with this version and cannot reconstruct earlier general activity.

9. The primary tree now preserves explicit source steps with lexical cards and operation connections. Reused construction internals need a verified copied expansion or a reviewed definition edit; drag rewiring now preserves draft-only loose pieces and empty connections; automatically bound helper expansion remains unimplemented. Helper templates are not claimed to be executed steps. Conditional helper dependencies in Léxico remain source candidates. 10. New full-passage AI scope is covered by local engine context, saved-request replay and simulated transports. The next user-requested generation will establish model-side translation quality; routine tests must not spend provider usage.
11. Rendered reuse covers available source/declaration steps and contextual local drafts. It offers known portions of longer readings but does not infer a new full sentence analysis. Very large changed-draft collections need incremental index synchronization before exceeding the current 1 MB RPC payload limit. Source77's two context-dependent intermediate stages have no standalone form and are skipped explicitly. See [reuse contract](../design/rendered-reuse.md).

Invalid Python syntax keeps a repairable raw card rather than an invented partial parse. See [canvas contract](../design/canvas-editor.md).
