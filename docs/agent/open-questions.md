# Remaining questions and release boundaries

1. Live linguistic usefulness remains unmeasured for the iterative authoring workflow. Claude model discovery was rechecked successfully (11 models), and installed Codex 0.153.4 initialization/scoped thread setup passed, both without generation. The historical Claude credit rejection remains unresolved by those checks. Run any live linguistic experiment only after an explicit separate budget; routine fixtures make no inference requests.
2. Attach and assess the actual historical Araújo PDF. Native PDF geometry, persistence, rotation and original colors were verified with a vector fixture; unusual font/CMap/codec cases remain untested.
3. Version 0.2.10006 is published for Windows x64, Linux x64 and both Mac architectures. Native packaged-app startup, bundled Git workspace preparation and real engine evaluation passed on all four runners. Manual installer acceptance on users' own systems and a real published-version upgrade remain untested. Developer ID/notarization credentials are still needed for seamless Mac distribution and automatic updates; Windows signing is also absent. See [installation guide](../installing.md).
4. Decide a portable contribution archive for managed PDFs, local draft history and AI provenance. Source comments retain stable evidence pointers; current Git export shares source/reference patches, not private local application data.
5. Unmarked identical insertion/reordering can be intrinsically ambiguous. Current code preserves stationary/unambiguous identities, uses explicit source IDs for durable edits, and keeps ambiguous orphan drafts for human reassociation. Avoid heuristic auto-migration of their PDF or AI evidence.
6. New analysis jobs can supply real saved PDF crop pixels when selected; text-only remains supported. Pixel geometry is verified with asymmetric vector fixtures under rotation and nonzero page origins. The actual historical scan/font/codec coverage remains open. Explicit grammar-correction submissions now grant dedicated, hash-guarded grammar-edit tools for the selected directory. Ordinary analysis tools still cannot patch the engine. Live linguistic correction quality has not been tested with a provider.
7. Full Araújo coverage tests concrete syntax, selected visual interactions, selected-engine output and structural graphs. It does not prove every possible edit linguistically valid, or certify future engine constructs. Extend the explicit adapter/capability inventory for new operations.

Ordinary local implementation and disposable-copy tests are authorized. The task does not authorize silently applying experimental edits to the historical corpus, publishing credentials, or granting editorial approval from matching generated output.

8. If a real translation stalls again, inspect its persisted phase/request ID and local usage report. The repair made no new live generation requests by user instruction. Logs start with this version and cannot reconstruct earlier general activity.

9. The primary tree now preserves explicit source steps with lexical cards and operation connections. Selected references expose their runtime object tree and static cross-source usage candidates; editable source steps require a verified copied expansion or a reviewed definition edit; drag rewiring now preserves draft-only loose pieces and empty connections; automatically bound helper expansion remains unimplemented. Helper templates are not claimed to be executed steps. Léxico includes every visible node; conditional helper dependencies remain source candidates. Occurrence notes survive formatting, unrelated edits and local definition wrappers, but changed subtree identities retain historical notes without heuristic reassociation. Notes remain local notebook data; published source definitions are portable. See [node interpretation contract](../design/node-interpretations.md).
10. New full-passage AI scope is covered by local engine context, saved-request replay and simulated transports. The next user-requested generation will establish model-side translation quality; routine tests must not spend provider usage.
11. Rendered reuse covers available source/declaration steps and contextual local drafts. It offers known portions of longer readings but does not infer a new full sentence analysis. Very large changed-draft collections need incremental index synchronization before exceeding the current 1 MB RPC payload limit. Source77's two context-dependent intermediate stages have no standalone form and are skipped explicitly. See [reuse contract](../design/rendered-reuse.md).

12. The canvas handles single-subtree mouse/keyboard edits and local loose-piece persistence. Multi-selection/group transforms and a portable shared forest are future work. Partial main stage evidence arrives in one evaluation response; independent loose pieces resolve asynchronously. Invalid Python syntax keeps a repairable raw card rather than an invented partial parse. See [canvas contract](../design/canvas-editor.md).

13. Source comments currently support section/subsection inheritance, but cannot clear an inherited section with an empty directive; the review path reports this without rewriting the neighboring parser. Pending lines can be inserted and published in any order through stable anchors. Arbitrary reordering/discarding of existing queued shells is not yet exposed. Legacy corpus readers see only the contiguous approved JSONL prefix; Studio also reads the portable sparse-reference companion. The palette follows the selected engine's constructor catalog. Local constructor pieces become named shared entries during the combined passage/lexicon review; unsupported dynamic constructor arguments remain explicit source code. See [next-passage contract](../design/next-passage.md).

14. The embedded dictionary is the local selected checkout, not an automatic mirror of the public deployment. Neologism rows remain consultation-only. Agent-created pieces retain exact verbal/nonverbal dictionary identities and definitions in candidate evidence; removed/changed pieces mark earlier evidence as historical. The ordinary pre-existing human picker retains full definitions but has no separate occurrence evidence ledger. Shared lexical declarations remain an explicit reviewed edit. See [dictionary contract](../design/dictionary.md).

15. Local authoring queue concurrency is three conversations, with one active turn per thread and one repair writer per grammar directory. Closing the window can retain the owner, while actual quit/sleep may interrupt work; ambiguous attempts require explicit retry. Codex has an observed output ceiling, not an exact billed-token cap. Cross-machine collaboration and a portable private-state archive remain outside this milestone.

16. Suggestions now use the supported full Navarro snapshot and bounded productive morphology; 1,227 of 8,293 current dictionary senses remain explicitly unclassified/unpinnable. More construction nesting, automatic unknown-root proposals, historical spelling/OCR alternatives and independent historical accuracy measurements remain future work. Unknown vocabulary requires an explicit root/class hint or a manually registered hypothetical lexical root and retains provisional status. Manual class choices that the selected engine silently replaces with dictionary information fail clearly; Studio does not fabricate missing dictionary IDs to override the engine. See [contract](../design/parser-lab.md).

17. Decomposed nominal readings may carry a surface-linked Navarro meaning, but equal surfaces do not establish etymology or equal paradigms: derived `moropotara` and dictionary `poropotara` differ under possession. Studio now carries nested semantic context to prompts and portable source publication. Native standalone Pydicate `semantic()`/`translation_prompt()` still use the engine's existing semantics; no engine API migration is included. Arbitrary helper bodies and stale dependency histories are omitted with explicit diagnostics. Additional productive families and historical validation remain open.

18. Studio multiline source comments use a reversible, content-bound `json-string-v1` extension in the existing `studio:v1` note. Studio import/export/reopen/approval decodes it, but the neighboring corpus parser used independently still returns the serialized string. A coordinated upstream decoder migration is separate work; never unescape all legacy strings heuristically. Live multilingual translation quality is unmeasured; routine tests exercise prompt/evidence contracts and simulated providers only. Explicit AI continuation starts a new provider attempt and does not imply exactly-once billing.

19. Experimental morpheme tracing compares annotated step surfaces; it is not
native engine provenance. Non-whitespace annotation/surface disagreement,
unresolved changed forms, repeated matches and unavailable stages can stop tracing. Shared-reference runtime internals have no editable source
step trace until explicitly copied into the canvas. The selected source tree and
loose pieces are supported; no engine changes are included.
